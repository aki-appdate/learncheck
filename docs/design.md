# LearnCheck デザイン方針

## 使う人と場面
- **研修担当**：PCの前で、資料とAIの問題案を見比べながら1問ずつ確かめる。急がない。「この問題の根拠はどこか」がいつも目に入っていてほしい。
- **受講者**：仕事の合間に、スマホで5分ほど。片手で押せて、間違えたらその場で資料のどこに書いてあったかが分かること。
- **研修の責任者**：結果を読んで、次のフォロー研修を決める。どの問題・どの部署でつまずいたかを、根拠の問題までたどれること。

## 性格を表す3語
**根拠が見える・端正・やさしい**

## 見た目の決まり
- **たとえ**：教科書の「余白」と「検印」。問題は本文に、根拠（資料の引用）は余白に添える。人が採用した問題には検印（丸い印）を押す。
  - 根拠の引用 … 若草色の地＋深緑の下線で印をつけ、資料のどのあたりの文か（位置の目盛り）も見せる。
  - 人の承認 … 採用した問題に「採用」の丸い印。AIの案のままの問題は「AIの案」、人が書き換えた問題は「人が修正」と文字で区別する。
- **色**：深緑（`brand`）を主役に、背景はわずかに緑みの白（`canvas`）、資料の面は薄い若草（`paper`）。正解・採用は `good`、注意は `warn`、根拠なし・不正解は `bad`。青と黄色のマーカーは使わない（CallNote・ReplyDesk と分ける）。
- **書体**：BIZ UDPゴシック（教材向けに作られたユニバーサルデザイン書体）。表の数字は BIZ UDゴシック（等幅）で桁をそろえる。大きな数字は BIZ UDPゴシックの太字（プロポーショナル）。明朝・装飾書体は使わない。
- **形**：角は小さく（2〜6px）。箱を並べるより、罫線（1px）と余白の列で区切る。影はダイアログだけ。検印だけが丸い。
- **余白と密度**：研修担当の画面は2列（本文／余白）。受講者の画面は1列で文字を大きく（問題文17px・選択肢16px・押せる高さ52px以上）。
- **文字の段階**：見出し 28/20/16px・本文 15px・補足 13px・ラベル 12px（字間を少し広げる）。
- **状態**：選択中＝墨の2px枠＋記号の塗り。押せない＝薄く＋理由を文章で。読み込み中・空・エラーは、何が起きているかと次にすることを書く。
- **アイコン**：インラインSVG、線の太さ1.75で統一。絵文字・✦などの飾り記号は使わない。
- **色だけに頼らない**：正誤は ○／×、根拠は ✓／！の記号と文字を必ず添える。

## グラフ
- 1系列は1色（深緑 `brand`）。正答率60%未満の問題だけ `bad` にし、「要フォロー」の文字を添える。60%の位置に1pxの基準線。
- 棒は太さ8〜12px、先端だけ丸める。値は棒の外に文字色で書く。どの値も画面上に文字で出ている（色や棒だけで読ませない）。
- 選択肢ごとの人数は、正解を `good`、誤答を灰色（`chart-rest`）。大きな数字は1画面に1つ（結果画面の平均点）。

## トップページの骨組み（姉妹アプリと分ける）
- CallNote・ReplyDesk は「左に見出し＋入口ボタン2つ、右に製品の見本カード」。LearnCheck はこの形にしない。
- **冒頭は教科書の1ページ**：本文（見出し・説明・入口）と、罫線1本で分けた**余白**（「テストができるまで」の4段の書き込み）。同じ大きさの箱を4つ並べない。
- **入口は目次の形**：立場ごとに1行。題名＋説明＋点線のリーダー＋矢印の四角。主役（研修担当）の矢印だけ深緑で塗る。
- **見本は1つだけ、動かせるもの**：確認カードと同じ並び（本文＝問題、余白＝照らし合わせの結果）。根拠の文の例を切り替えると、照らし合わせと「採用」を押せるかが変わり、押すと検印が付く。見本の図と「試せる欄」を別々に置かない。

## 今回足した決まり
- **選択中の切り替えボタン**（問題の数・難しさ・見本の例）：墨の枠を2px相当（1px枠＋内側1pxの影）＋太字。黒の塗りつぶしは使わない（受講画面の選択肢と同じ見え方にそろえる）。
- **補足の注記**：本文の説明と別に添える注意は、教科書の脚注のように「※」でぶら下げる（12px・`ink-muted`）。
- **直している間も余白を消さない**：問題を直すフォームでも、余白に「入力中の根拠の文」の照らし合わせ結果を出し続ける。
- **小窓**：Escで閉じる・開いたら中にフォーカス・Tabは小窓の中で回る・閉じたら開いたボタンへ戻す。後ろの画面はスクロールさせない。
- **スマホの表**：列を減らし、減らした項目は名前の下に小さく添える（横スクロールの先に「未受講」などを隠さない）。部署名のようなカタカナの語は途中で折らない（`word-break: keep-all`）。
- **見出しは折らない**：見出しの横の補足が長いときは、補足のほうを下の行に送る。
- **同じ名前のテスト**：選ぶ欄では公開日を添えて見分ける。
- **スマホのヘッダー**：切り替える画面が1つしかない受講者には、画面の切り替えの行を出さない。架空データの注意書きは1行に収める。
- **受講結果**：間違えた問題は「× あなた」と「○ 正解」を並べる（取り消し線は使わない。ReplyDesk の赤ペンと分け、受講者にきつく見せない）。結果から「もう一度受ける」に直接行ける。
